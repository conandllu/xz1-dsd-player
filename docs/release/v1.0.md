**首个公开版本（1.0）**：把安卓手机变成"随身数播"——不经过 AudioFlinger，用 libusb 在用户态直接跑
UAC2 等时输出，把 PCM / DSD 位流逐字节送进 USB DAC。

## 这个版本能做什么

- **独占输出**：播放期间 DAC 被本应用独占（`detach` 内核 `snd-usb-audio` + claim UAC2 接口），
  系统通知、其它 App 都不会混进来；停止/退出自动归还。
- **DSD 双路**：DSD Native（DSD64~512）优先，失败自动回退 DoP（176.4k/352.8k/705.6k），
  暂停/欠载继续送合法 DoP 静音帧，不掉锁定。
- **真 24bit**：24bit FLAC 不再被平台解码器降到 16bit —— 自己按帧切、显式要 float 输出，
  再缩放成 24-in-32 送出（本地与 WebDAV 流播都走这条路）。
- **多来源曲库**：本地曲库 / WebDAV / 在线 Qobuz 三选一，共用同一套网格、搜索与排序。
  WebDAV 支持目录封面、点击直连流播、长按下载到 `Music/WebDAV/…`。
- **界面**：单 Activity + 四 tab，网格（2/3/4 列）与列表两种形态，横屏切左侧导航，
  播放队列、三种播放模式、切歌清零进度不乱跳。

## 两个 APK 怎么选

| 文件 | 包名 | 说明 |
|---|---|---|
| `XZ1-DSD-Player-v1.0-dsd.apk` | `com.dsd.player` | 原版：独占 USB，暂停时仍保持独占（最稳的位流输出） |
| `XZ1-DSD-Player-v1.0-companion.apk` | `com.dsd.player.companion` | 共存版：默认「让出 USB 独占」，暂停/停止时把 DAC 交回系统，官方 Apple Music 等可以直接用；仍可播本地 ALAC/m4a |

两个包**可以同时安装**。

## 安装

1. 下载对应 APK，允许"安装未知来源应用"；
2. 首次启动按提示授予「所有文件访问」（DSD 文件不在媒体库里，缺这个权限曲库里看不到 `.dsf/.dff`）；
3. 插上 USB DAC，弹权限框时勾选"默认"并允许；
4. **若之前装过 debug 测试包，请先卸载**——本版本的签名与原 debug 包不同，直接覆盖会报
   "应用未安装 / 签名不一致"。

## 已知限制

- 本地 `.mp3` 不支持；DST 压缩的 DFF 不支持；WebDAV 里的 DSF/DFF 需下载后播放
- Apple Music 流是 FairPlay 加密，本项目不绕过 DRM（用共存版的"让出独占"让官方 App 自己输出）
- 采样率漂移只做水位重置，未做连续 ASRC
- 凭据（WebDAV 密码 / Qobuz token）目前明文存本机 SharedPreferences（已关 `allowBackup`）
